# Line Balance Chart

เว็บแอปทำ Line Balance / Man-Machine Chart (ไม่ต้อง build อัปโหลดทั้งโฟลเดอร์ขึ้น host ได้เลย)
เข้าด้วยชื่อผู้ใช้ + รหัสผ่าน และบันทึกงานอัตโนมัติลง Supabase

## เพิ่มผู้ใช้ (ผู้ดูแลทำใน Supabase)
1. Authentication → Users → Add user → Create new user
2. Email: พิมพ์ `ชื่อผู้ใช้@lb.local` เช่น `bee@lb.local`
3. ตั้งรหัสผ่าน และติ๊ก **Auto Confirm User**
4. ผู้ใช้เข้าเว็บแล้วพิมพ์แค่ `bee` กับรหัสผ่าน

## สิทธิ์ผู้ใช้และถังขยะ
รัน `supabase/roles_trash.sql` ครั้งเดียว (ผู้ใช้เดิมทุกคนเป็น **ผู้แก้ไข** ก่อน)
- **ผู้แก้ไข (editor)** บันทึก แก้ ลบเข้าถังขยะ กู้คืน ลบถาวรได้
- **ผู้ดูอย่างเดียว (viewer)** ดูงาน ประวัติ ลองสมมติ ส่งออก Excel ได้ แต่แก้/บันทึก/ลบไม่ได้ (ฐานข้อมูลบล็อกด้วย RLS อีกชั้น)
- ผู้ใช้ที่ไม่มีแถวใน `lb_roles` เป็นผู้ดูอย่างเดียวโดยอัตโนมัติ ผู้ใช้ใหม่ที่สร้างหลังรัน SQL ต้องเพิ่มสิทธิ์เอง (คำสั่งอยู่ท้ายไฟล์ SQL)
- งานที่ลบจะเข้าถังขยะ 30 วัน แล้วลบถาวรเองเมื่อผู้แก้ไขเปิดเว็บ
- ถ้ายังไม่รัน SQL เว็บจะทำงานแบบเดิม (ทุกคนแก้ได้ ลบแล้วหายถาวร)

ปิดการสมัครเอง: Authentication → Sign In / Providers → ปิด **Allow new users to sign up**

## ส่งออกรายงาน PDF / รูป
ปุ่ม **ส่งออกรายงาน PDF / รูป** (แท็บ Man-Machine Chart และหัวข้อ 4 ของแท็บ Process Flow) เปิดหน้าต่างให้กรอกชื่อบริษัท โลโก้ ผู้จัดทำ ผู้ตรวจสอบ หมายเหตุ (จำไว้ในเครื่องนั้น)
- **PDF**: กด “พิมพ์ / บันทึกเป็น PDF” แล้วเลือกปลายทางเป็น Save as PDF (A4 แนวนอน)
- **PNG**: โหลดตัวสร้างรูปเฉพาะตอนกด ไม่ต้องติดตั้งอะไร
- ผู้ดูอย่างเดียวส่งออกได้เหมือนผู้แก้ไข

## แสดงว่าใครเปิดหรือแก้งานอยู่ (Realtime)
ใช้ Supabase Realtime (Presence + Broadcast) ไม่ต้องรัน SQL เพิ่ม
- ขึ้นแถบบนหน้าจอ เช่น “สมศักดิ์ กำลังแก้งานนี้อยู่” หรือ “มานี เปิดงานนี้อยู่”
- เมื่อมีคนบันทึกงานเดียวกัน อีกฝั่งเห็น “เพิ่งบันทึกเมื่อ …” พร้อมปุ่ม **โหลดเวอร์ชันล่าสุด**
- ต้องเปิด Realtime ในโปรเจกต์ Supabase (ค่าเริ่มต้นเปิดอยู่) ถ้า Realtime ใช้ไม่ได้ ระบบอื่นทำงานปกติ แค่ไม่มีแถบนี้

## สำรองข้อมูลและ log ข้อผิดพลาด
รัน `supabase/backup_logs.sql` ครั้งเดียว (หลัง `roles_trash.sql`)
- **สำรองอัตโนมัติ:** ทุกวัน 03:00 เวลาไทย เก็บงานทั้งหมดลงตาราง `lb_backups` ไว้ 30 วัน (เฉพาะผู้แก้ไขอ่านได้) วิธีกู้อยู่ท้ายไฟล์ SQL
- **Log ข้อผิดพลาด:** เมื่อหน้าเว็บเจอ error หรือบันทึกไม่สำเร็จ ระบบส่งข้อความสั้นๆ ลงตาราง `lb_errors` (ชื่อผู้ใช้ ชื่องาน ข้อความ เบราว์เซอร์) ดูได้ที่ Supabase → Table Editor เก็บ 90 วัน ส่งไม่เกิน 5 รายการต่อการเปิดหน้า
- **สำรองเป็นไฟล์:** ในหน้าต่าง “งานที่บันทึกไว้” มีปุ่ม **ดาวน์โหลดสำรองทุกงาน (.json)** และ **นำเข้าจากไฟล์สำรอง** (ผู้แก้ไขเท่านั้น) ควรดาวน์โหลดเก็บนอกระบบเป็นระยะ เพราะสำรองอัตโนมัติอยู่ในฐานข้อมูลเดียวกัน ถ้าโปรเจกต์ Supabase หายจะหายตามไปด้วย
- ถ้ายังไม่รัน SQL เว็บทำงานปกติ แค่ไม่มี log

## ความเร็ว
ไลบรารี Excel (SheetJS, ExcelJS) โหลดเฉพาะตอนกดอัปโหลด ส่งออก หรือดาวน์โหลดแม่แบบ ครั้งแรกที่กดอาจรอครู่หนึ่ง

## มือถือ / แท็บเล็ต และติดตั้งเป็นแอป
- บนหน้าจอสัมผัส ปุ่มและช่องกรอกใหญ่ขึ้น (สูง 44px ตัวอักษร 16px กัน iPhone ซูมเอง) ตารางเลื่อนแนวนอนได้ลื่น คอลัมน์ชื่อทรัพยากรค้างซ้ายตอนเลื่อน
- กราฟ Man-Machine มีปุ่ม − + พอดีจอ และใช้สองนิ้วถ่างซูมได้ บนมือถือเปิดมาจะพอดีจออัตโนมัติ
- **ติดตั้ง:** Android/Chrome กดปุ่ม “ติดตั้งแอป” ที่แถบบน (ขึ้นเมื่อเบราว์เซอร์พร้อม) ส่วน iPhone เปิดด้วย Safari แล้วกดแชร์ → เพิ่มลงในหน้าจอโฮม
- เปิดแอปได้แม้เน็ตหลุด แต่ดึง/บันทึกงานต้องใช้เน็ต (ระบบบันทึกแจ้งสถานะออฟไลน์ให้เหมือนเดิม) ต้องเปิดผ่าน https เท่านั้น
- ถ้าเพิ่ม/เปลี่ยนไฟล์ใน `js/` ให้เปลี่ยนเลข `CACHE` ใน `sw.js` (เช่น `lb-v2`) เพื่อให้เครื่องที่ติดตั้งไว้อัปเดตทันที

## ไฟล์
- `index.html` แอปหลัก (หน้าจอและการเชื่อม Cloud)
- `js/calc.js` ตัวคำนวณ Takt / โหลด / คอขวด / Balance Efficiency / ตารางเวลา (ฟังก์ชันล้วน ไม่แตะหน้าจอ)
- `js/parse.js` ตัวอ่านไฟล์ Excel / Process Flow และตัวจัดไลน์อัตโนมัติ
- `tests/` ชุดทดสอบการคำนวณ รันด้วย `npm test` (ต้องมี Node 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)
- `config.js` Supabase URL + anon key (anon key ใส่ใน repo public ได้ ห้ามใส่ service_role)
- `supabase/schema.sql` ตารางเก็บงาน (ติดตั้งใหม่) ทุกบัญชีเห็นงานชุดเดียวกัน
- `supabase/shared.sql` ปรับตารางเดิมให้แชร์งานข้ามบัญชี (รันครั้งเดียว)
- `supabase/versions.sql` ตารางประวัติเวอร์ชัน (รันครั้งเดียว)
- `manifest.webmanifest`, `sw.js`, `icons/` ติดตั้งเป็นแอป (PWA)
- `js/lazy.js` โหลดไลบรารี Excel ตอนใช้ · `js/errlog.js` ส่ง log ข้อผิดพลาด
- `supabase/backup_logs.sql` สำรองอัตโนมัติ + log (รันครั้งเดียว หลังไฟล์ด้านล่าง)
- `supabase/roles_trash.sql` สิทธิ์ผู้ใช้ 2 ระดับ + ถังขยะ (รันครั้งเดียว หลัง 3 ไฟล์ข้างบน)
